# Examples — itekit-examples

## 📌 Overview
This directory contains example datasets and model definitions to illustrate the **data structure and organization** of the project.  

All files are representative; **no full-scale execution or training is provided**.  

> **Important:** All directories and files under `logs/` are **automatically generated** by running the example scripts (`*_example.py`). Users do **not** need to create them manually.

## 📄 Subfolder Descriptions

### 🔹 mymodels/
- Contains **self-registered models**  
- Demonstrates **model organization and registration mechanism**  

### 🔹 pima/
- Example dataset based on the **Pima Indians Diabetes dataset**  
- `data/` → input data files  
- `logs/` → **all output is automatically generated** by running `pima_diabetes_example.py`  
  - Six **run directories** (`run_1` … `run_6`)  
  - **`statics/`** → global summary statistics for all runs  
  - **`statics_runid/` directories** → statistics for single or multiple run IDs  
- `pima_diabetes_example.py` → **reference script for illustration only**  

### 🔹 stroke/
- Example dataset for stroke prediction  
- `data/` → input data files  
- `logs/` → **all output is automatically generated** by running `stroke_example.py`  
  - Five **run directories** (`run_1` … `run_5`)  
  - **`statics/`** → global summary statistics for all runs  
  - **`statics_runid/` directories** → statistics for single or multiple run IDs  
- `stroke_example.py` → **reference script for illustration only**
